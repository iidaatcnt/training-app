# 研修チェック＆自己評価システム (training-app)

受講者が選択式タップ（1〜5段階）で手軽に自己評価・振り返りを回答でき、**回答データを即時集計・グラフ分析**できるWebアプリケーションです。

---

## 🌟 主な機能・特長

1. **選択式タップで回答完了（全8問・5段階評価）**
   * **設問1**: 「大きな声で挨拶ができたか？」（5段階）
   * **設問2〜8**: ビジネスマナー・基本行動（笑顔、身だしなみ、時間厳守、傾聴、敬語、メモ取り、報連相）※自由にカスタマイズ可能
   * スマートフォンでも押しやすい大きなボタンスタイル
   * リアルタイム合計スコア（40点満点）＆達成率の自動計算
2. **Supabase による安全なユーザー認証**
   * メールアドレス ＋ パスワードによるログイン／新規登録
   * **パスワード忘れ対応**: パスワード再設定メールの自動送信と再設定画面を完備
3. **クラウド保存 ＆ 項目別平均スコア分析**
   * 回答がすべて1〜5の数値データとして保存されるため、集計・分析が容易
   * 「どの項目の得点が低く、強化が必要か」が一目でわかる項目別バーグラフ分析
   * 過去の受講履歴一覧

---

## 🚀 セットアップ手順

### 1. Supabase の準備
1. [Supabase](https://supabase.com/) で新規プロジェクトを作成します（日報アプリと同じプロジェクトでもOKです）。
2. 左メニューの **「SQL Editor」** を開き、本リポジトリ内の `supabase_schema.sql` の内容を貼り付けて **「Run」** を実行します。
3. 左メニューの **「Project Settings」>「API」** から、以下をコピーします：
   * `Project URL`
   * `anon public key`

### 2. アプリの起動・設定
1. `index.html` をブラウザで開くか、Cloudflare Pages 等にホスティングします。
2. 画面右上の **「⚙️ 設定」** ボタンをクリックし、`Project URL` と `anon public key` を入力して保存します。
3. ログイン後、すぐにチェック・回答を開始できます。
